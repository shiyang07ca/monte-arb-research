Day 8 · Cross-venue schema

同一张表，三种语义

目标：把三个场所的盘口放进同一张研究表，同时保留不可直接类比的字段，不补零、不冒充时间。

最小 schema

venue, market, instrument_type, source_timestamp, received_at,
price_semantics, bid, ask, size, funding_rate, funding_timestamp,
precision, quality_flags, raw_ref

规则

问题处理禁止
时间保留 venue 原始字段，统一 UTC用 received_at 冒充 source_timestamp
缺字段留空 + 标记补 0 或补估计值
同名字段列明 not_equivalent直接相减或直接拼接
失败请求保存 0 字节 + HTTP 状态当作网络波动忽略
