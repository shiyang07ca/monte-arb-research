Funding 现金流参考卡

先用仓位方向和 funding rate 判断付款/收款，再用 index 与数量计算一条纸上现金流。API 的 value 不能直接当成组合收益。

一、官方规则

  • 永续合约没有到期日，funding payment 在每个整点发生。
  • 正 funding rate：多头向空头支付；负 funding rate：空头向多头支付。
  • 官方账户资金费公式：
funding_cash_flow
= − position_sign
  × index_price
  × funding_rate
  × base_quantity
  × multiplier

long  position_sign = +1
short position_sign = −1

负数表示该账户付款，正数表示该账户收款。

二、字段不要混用

字段当前可做什么当前不能做什么
ratefunding rate 方向和纸上公式输入不能单独推出账户金额
index_price官方公式中的价格输入缺少历史对齐时不能伪造结算价
value保留为 API 观察字段不能直接相减称为 funding PnL
direction保留为 API 观察字段不能代替账户 long/short sign
账户 ledger验证真实扣款/入账当前公开快照中尚未取得

三、真实本地样本

市场时间rateAPI valueAPI direction
WTI（145）2026-08-03T00:00Z0.00040.00032286long
BRENTOIL（159）2026-08-03T00:00Z0.00040.00033548long
这还不是历史现金流。

该 funding 行没有同时提供你的仓位、时间对齐的 index、实际数量和账户扣款/入账；因此 ledger 状态是 paper_only 或 unknown，不能写成 verified。

四、纸上例子

WTI：quantity = 0.134
index = 74.670（当前 orderBookDetails 示例输入）
rate = 0.0004

多头：−1 × 0.134 × 74.670 × 0.0004 = −$0.0040023120
空头：+1 × 0.134 × 74.670 × 0.0004 = +$0.0040023120

这里的 index 不是该 funding 时点的历史对齐值，所以只能作为教学计算，不能当作真实账户 PnL。

五、验证闸门

  1. 确认 position sign 和实际 base quantity；
  2. 取得同一 funding 时点的 index / settlement price；
  3. 解释 API value、rate、direction 的单位和语义；
  4. 用账户 funding ledger 回读实际扣款或入账；
  5. 两腿分别记账，再合并组合现金流。
