同步报价时间与准入

“同一轮请求”只是一种采集组织方式，不自动等于同一市场时刻。

三种时间

字段含义可以比较什么
request_started_ns本机开始发请求采集窗口起点
response_received_ns本机完整收到响应同进程接收先后与偏差
source_time_ms交易所快照/事件时间只有两边都提供且语义一致时才跨源比较

准入顺序

盘口有效？
→ economic_object == same？
→ contract weights matched？
→ oracle states known and equal？
→ receive skew within limit？
→ eligible

任何关键未知/冲突 → exclude

保留原始观察

  • 原始观察保存身份、三种时间、bid/ask、数量和原始哈希。
  • 缺失时间保留 None，不得用接收时间代填。
  • exclude 是派生决定，不删除原始数据。
  • 以后取得合约权重和 oracle 状态后，可以重算准入。

当前决定

WTI ↔ xyz:CL = exclude
BRENTOIL ↔ xyz:BRENTOIL = exclude

reasons:
ECONOMIC_MAPPING_UNKNOWN
CONTRACT_WEIGHT_UNKNOWN
ORACLE_STATE_UNKNOWN
SOURCE_TIME_NOT_COMPARABLE

盘口接近不能覆盖这些阻断项。
