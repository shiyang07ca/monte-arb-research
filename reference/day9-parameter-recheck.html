Day 9 · Parameter re-check

参数矩阵是快照，不是事实表

核心判断

类型作用例子（Lighter WTI/BRENTOIL）变化频率
合约级决定能不能下单、能开多少仓IMR/MMR/CMR、最小基础数量、小数位、费率、funding clamp低（交易所规则），但可能被调整
状态级决定有没有机会mark/index 价格、成交量、成交笔数、持仓量 OI高（每分钟变化）

2026-08-12 真实对比结果（vs 2026-08-05）

  • 合约级参数：0 变化（两腿都是）——规则没有变；
  • 状态级参数：各 10 项变化——价格、成交量、持仓量全部移动；
  • WTI：mark 74.692 → 82.999（+11%）；OI 74,515 → 65,172（价格涨但持仓降）；成交笔数 9,100 → 19,587；
  • BRENTOIL：mark 79.03 → 87.96（+11%）；OI 12,390 → 62,874（+407%）；成交额 138 万 → 629 万（+354%）但笔数 8,188 → 8,273（几乎不变）。

三个必须记住的解读

  1. 成交额暴涨但笔数不变 → 平均每笔金额变大：不是散户变多，更像大资金或程序化单笔规模扩大；需要成交分布佐证，不能直接下结论。
  2. 价格涨但持仓降 → 不能断言驱动力量：可能是空头平仓推涨，也可能是多头减仓后的残局；需要逐笔/资金流证据，不能凭两个数字猜。
  3. 规则没变 ≠ 机会存在：合约参数只回答「能不能下单」；「有没有机会」必须由状态数据 + 走档 + 成本模型回答。

操作检查清单

  1. 任何参数矩阵都要带 captured_at 时间戳；
  2. 每次重新抓取保存原始响应 + HTTP 状态 + 延迟 + SHA-256；
  3. 对比时自动 diff，不肉眼看 40 个字段；
  4. 未知字段保持 unknown，不填零、不插值；
  5. 合约级和状态级分开记录，结论分别表述。
