经济对象与价格状态

跨场所 RWA 在进入价差计算前的失败关闭检查。

两个独立问题

  1. 静态定义：两边是否为同一基准、单位、报价/结算币和完整合约月份？
  2. 动态状态：报价时刻两边是否处于相同 external/internal/roll 状态？

静态定义通过，不代表动态状态通过；任一未知都不能进入收益样本。

经济对象字段

  • 完整市场身份
  • 资产类别与基准
  • 单位与乘数
  • 报价币与结算币
  • 合约月份代码与年份
  • 外部时段与定价规则
  • 每个字段的证据来源

价格状态证据

  • 外部市场是否开放
  • external price 是否可用
  • oracle 是否 fresh
  • 是否正在展期切换
  • 当前/次月权重
  • 来源时间，不只接收时间

决定顺序

已有字段冲突  → not_comparable
无冲突但缺字段 → unknown
全部静态字段相同 → comparable_definition
再检查同一时刻价格状态
状态不同或未知 → 不进入价差样本

禁止的捷径

  • 不能按 symbol 相似度自动配对。
  • 不能把“一桶”解释为同一基准。
  • 不能只看时钟推断 oracle 状态。
  • 不能把“盘口仍在动”解释为外部价格仍可用。
  • 不能自行选择互相矛盾的官网月份文字。
