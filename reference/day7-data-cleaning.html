Day 7 · Data quality

数据清洗不是把异常删干净

目标是让每条样本都能回答：来自哪里、时间是什么、为什么进入或不能进入某项统计。

最小规则

问题处理禁止
时间统一 UTC，保留原 timestamp混用本地时区
重复保留原始，标记并显式复核静默覆盖
缺失小时标记 gap插值成“真实”数据
非正/非法值保留原行，排除对应统计填 0 或静默删除
异常跳点保留并加 flag自动当作错误删除
训练测试按时间顺序切分随机打乱未来信息

准入判定

raw row
  → UTC + source path
  → duplicate / gap / invalid flags
  → price_stats_eligible
  → funding_stats_eligible
  → combined_pair_eligible

Day 7 的“干净”不是没有异常，而是异常有原因码、原始值可回溯、统计准入可重跑。

时间切分

train60%只用于描述/拟合规则
validation20%用于检查规则迁移
test20%冻结规则后再看
当前样本限制

candle 每市场只有 500 行，API 文档说明单次最多返回 500 根；当前范围只到 2026-08-06，未覆盖 Day 5 的官方展期示例窗口。
