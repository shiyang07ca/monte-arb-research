# Monte Arb Research

这是一个跨场所永续价差研究与实时模拟仓库。当前课程不发送真实订单。

## 从这里开始

1. 阅读 [`MISSION.md`](./MISSION.md) 了解最终能力和限制。
2. 阅读 [`resource/plan.md`](./resource/plan.md) 了解 Day12–21 安排。
3. 从 [`curriculum/day12.md`](./curriculum/day12.md) 开始下一课。

## 目录

- `curriculum/`：当前每日实战任务。
- `resource/`：课程计划、研究摘要和原始参考资料。
- `notes/`：仍有研究价值的市场与数据笔记。
- `learning-records/`：历史学习记录，不等于当前掌握证明。
- `lab/`：旧研究中仍可复现的代码和公开数据。

新的正式代码将在 Day12 起进入 `src/monte_arb/`，测试进入 `tests/`，运行证据进入 `research/`。
