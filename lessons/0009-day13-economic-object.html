关键模型

经济对象是一组字段，不是 symbol

EconomicSpecification(
    identity,
    asset_class,
    benchmark,              # WTI 或 Brent
    unit,                   # barrel
    quote_currency,
    settlement_currency,
    contract_month_code,
    contract_year,
    contract_reference_status,  # 观察时刻是否确认
    external_session,
    pricing_rule,
    evidence,
)

单位相同只解决数量解释；基准、月份和价格机制仍可能不同。程序先检查已知冲突，再检查未知字段。

点击查看映射器对三组配对的真实输出。
价格状态

盘口在动，不代表外部基准在动

Lighter 和 trade.xyz 都能在外部价格不可用时使用订单簿衍生的内部价格。trade.xyz 还单独保存 external price：外部休市后它冻结在收盘价，而 oracle 可继续内部更新。因此“有盘口”和“oracle 在变”都不能证明两边正跟踪同一外部合约。

只知道墙上时钟时，结果保持 unknown。
