Day 6 · Funding cash flow

Funding 不是两个 API 字符串相减

今天只做一件事：把 funding rate、仓位方向、数量和 index 连接成一条可解释的纸上现金流。

研究任务：Lighter WTI（market_id=145）与 BRENTOIL（market_id=159）相对价值研究。

今天的唯一胜利

看到 funding 数据时，先判断谁付款、谁收款；然后知道还缺什么才能算真实账户现金流。未知字段必须保持 unknown。

本课导航 1. 官方规则 · 2. 字段分工 · 3. 真实样本 · 4. 纸上账本 · 5. 迁移验收 · 打印版参考卡

1. Funding 的核心规则

Lighter 官方 Funding 文档说明，永续合约没有到期日，funding payment 在每个整点发生。正 funding rate 时，多头向空头支付；负 funding rate 时，空头向多头支付。

funding_cash_flow
= − position_sign
  × index_price
  × funding_rate
  × base_quantity
  × multiplier

long  position_sign = +1
short position_sign = −1
符号先于算术

结果为负表示这个账户付款，结果为正表示这个账户收款。先看 rate 的正负，再看仓位 sign；不要先看 API 的 direction 字符串。

主要来源：Lighter Funding。API 入口：fundings。

2. API 字段与账本字段不是一回事

字段今天如何使用边界
rate判断 payer/receiver，作为公式输入单独不能推出金额
value保留原始观察单位和账户映射未核验，不能直接相减
direction保留原始观察不代替账户的 long/short position sign
index_price官方公式的价格输入必须与 funding 时点对齐
cash_flow两腿分别记账未取得账户 ledger 前只能 paper_only
