## 保留的共学原则

原课程强调的以下原则继续保留：

1. 区分屏幕价差和扣除成本后的可执行净收益；
2. 记录资产、规模、路径、成本和失败原因；
3. 把一次观察变成可重复查询、脚本或工作流；
4. 使用成本模型、模拟或 paper trading 判断是否存在 edge；
5. 把学习、研究和真实交易风险分开。

## v6 的结构

课程不再按“每天解释一个 Lighter 字段”线性推进，而是采用一个深案例加两个迁移案例：

```text
Day 1–7   Lighter 深案例：问题、合约、价格、展期、funding、数据质量
Day 8–14  交易执行：跨场所数据、盘口走档、双腿状态、净现金、样本外回放
Day 15–21 跨场所与基础设施：CEX/链上永续、EVM 只读、库存、风险、持续采集、答辩
```

每天都必须有：

- 真实数据或故障场景；
- 一个运行或修改代码的动作；
- 一次闭卷解释；
- 一个新市场、方向、状态或故障的迁移；
- 一个可复查文件或测试结果。

HTML 只做可视化、模拟器和即时反馈，不再作为唯一验收方式。

## 三种状态分开记录

```text
学习状态：能解释 → 能运行 → 能复现 → 能修改 → 能迁移
研究状态：资料足够继续验证 / 暂时不成立 / 关键资料缺失
交易状态：No-Go / Paper-only / Supervised experiment / Live
```

完成 lesson 不等于策略成立；策略研究有信号也不自动授权真实交易。

## 课程边界

- 前 21 天研究资金为 `$0`；
- 不连接私钥、不保存凭据、不签名、不发真实订单；
- EVM 只安排只读基础：RPC、ABI、事件、余额、池子状态和报价；
- 未知字段保持 `unknown`，不默认填零；
- 研究结论必须带证据路径、时间范围和限制。
