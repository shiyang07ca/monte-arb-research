# Day 9 — 参数重新核验：快照不是事实表

## 唯一问题

旧 instrument matrix 是 2026-08-05 的快照；7 天后重新抓取，哪些参数变了、哪些没变，分别意味着什么？

## 实际动作（2026-08-12）

- 抓取 3 个公开只读响应，全部 HTTP 200，保存原始 JSON + manifest（HTTP 状态、请求/接收时间、延迟、SHA-256）：
  - `GET /api/v1/orderBooks`（230 个市场的规格列表）
  - `GET /api/v1/orderBookDetails?market_id=145`（WTI）
  - `GET /api/v1/orderBookDetails?market_id=159`（BRENTOIL）
- 编写 `lab/day9_parameter_recheck.py`：抓取 + 逐字段 diff + 分类（合约级/状态级）。
- 编写 `lab/test_day9_parameter_recheck.py`：7 个测试全部通过。

### 状态级（决定有没有机会）：各 10 项变化

| 字段 | WTI 旧→新 | BRENTOIL 旧→新 |
|---|---|---|
| mark_price | 74.692 → 82.999（+11%） | 79.03 → 87.96（+11%） |
| index_price | 74.670 → 83.065 | 79.04 → 88.12 |
| 日成交额 | 6,998,416 → 16,683,935 | 1,383,836 → 6,292,402（+354%） |

## 解读（含边界）

1. **成交额暴涨但笔数几乎不变（BRENTOIL）**：平均每笔成交金额变大。可能是大资金/程序化进场，也可能只是价格抬高放大了名义额。没有成交分布数据前，不能断言「散户变多」或「资金入场」。
2. **WTI 价格涨 11% 但 OI 下降**：单看两个数字无法区分「空头平仓推涨」还是「多头减仓」。需要逐笔成交方向或资金流数据，不能凭两个数字下结论。
3. **合约规则没变 ≠ 机会存在**：参数核验只回答「能不能下单」。机会是否存在，必须由状态数据 + 盘口走档 + 完整成本模型回答（Day 11–13）。
