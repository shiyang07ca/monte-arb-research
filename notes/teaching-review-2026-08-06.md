# 教学设计复核：10 天计划的补强与边界

## 复核结论

独立复核确认当前计划的主顺序合理：

```text
合约语义 → 数据审计 → 统计检验 → 成本与执行回放 → 决策
```

十天的目标不是证明盈利，而是让学习者能够独立复现证据、发现价格和数据语义风险、完成最小纸上回放，并在 Day 10 把三个判断分开：

| 判断层级 | 当前含义 |
|---|---|
| 学习状态 | 能解释、复现、审计、修改并重新运行研究材料 |
| 研究状态 | `Go` 只表示证据足以继续纸上验证；`No-Go` 表示已知结果否定候选；`Blocked` 表示关键证据未知 |
| 真实执行 | 本阶段固定为 `No-Go`，不连接私钥、不充值、不发单 |

## 每日学习循环

每天 30–90 分钟，默认 60 分钟：

1. 5 分钟闭卷回忆前一日的事实、公式和未知项；
2. 10–15 分钟只读官方资料和仓库原始证据；
3. 15–50 分钟完成一个最小实验或纸上计算；
4. 5–10 分钟关闭资料，口头解释并记录明日唯一动作。

每个产出固定包含：

- 已确认事实及来源；
- 自己计算或推导的结果；
- 未知项及其证据缺口；
- 对 `Go / No-Go / Blocked` 的影响。

## 10 天内不能承诺

当前共同小时样本约 21 天，funding 约 31 天。因此十天内不能承诺：

1. 长期协整、稳定均值回归或正期望；
2. 费用后盈利或真实 funding 净现金；
3. 目标数量的持续深度、部分成交和退出能力；
4. 完整清算、单腿恢复和异常状态模拟；
5. 所有市场时段、oracle stale 阈值、展期边界和恢复行为；
6. 账户、地区、RFQ、费率等级或交易权限；
7. EVM、Solidity、钱包、MEV、跨链、DEX 或生产级执行能力；
8. 任何收益、策略 edge 或真实交易建议。

## Day 10 最低决策输出

必须分别写出：

```text
Learning status: Pass / Not yet
Research status: Go / No-Go / Blocked
Live execution status: No-Go
```

当前仓库证据下的预期结果是：学习满足验收标准即可 `Pass`；研究因历史深度、funding 账本、盘口退出和权限等证据不足保持 `Blocked`；真实执行保持 `No-Go`。

## 复核中补强的最小实验

Day 3 不再只要求手工查看市场矩阵，新增一个无副作用的测试：

```bash
python3 -m unittest lab.test_audit_lighter_rwa
```

测试检查：

- WTI/BRENTOIL 的 `market_id` 和 `perp` 类型；
- 数量计算所需的最小基础数量、最小报价金额、乘数、价格和数量精度；
- `$10` 纸上报价金额的向上取整；
- 错误 market id 会被报告。

这个测试只验证当前公开市场快照的字段和数量可行性，不代表历史深度、成交概率、账户权限或真实盈利能力。
