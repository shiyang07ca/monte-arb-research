# 套利研究操作台产品规划

> 状态：当前产品与开发规划
>
> 更新：2026-08-22
>
> 产品范围：只读研究，不发送订单

## 1. 产品目标

持续建设一个可运行、可扩展、可二次开发的套利研究操作台。每天的共学用于增加真实数据、脚本、分析模块、页面或工程能力，并讲清实践中不可缺少的概念；产品功能不按课程日次拆分。

系统应支持：

```text
浏览市场与数据健康
→ 发现值得研究的关系或异常
→ 进入专题模块分析历史与机制
→ 用指定规模验证执行摩擦
→ 导出可复现数据和方法
→ 将结果实现成可复用采集器、指标或诊断器
```

## 2. 产品职责范围

### 负责

- 公开市场数据和经明确授权的只读市场观察采集；
- 市场目录、标的身份、时间语义和数据健康；
- Screener、专题分析、机制诊断、执行成本估算和历史回放；
- 原始证据、派生数据集、CLI、稳定 JSON/CSV 接口和浏览器页面；
- 把研究结果转成后续可以重复运行的模块。

### 不负责

- 发送订单、签名、连接执行客户端；
- 管理真实仓位、保证金或自动风控；
- 把单次快照、最高 APY 或最好历史样本称为可盈利策略；
- 用固定教学表单要求用户提交解释、假设或选择题。

`monte-fox` 继续负责 Variational CL/BZ 的生产研究与交易实现。本仓库只读取其脱敏市场观察或明确导出的数据，不读取密钥，不修改其运行状态。

## 3. 页面与模块

### `/workbench`：Dashboard

职责：展示模块入口、最新摘要、数据健康和当前可用数据集。

不承担：完整大表、详细模型参数、原始 JSON 或专题内全部图表。

### `/workbench/markets`：全市场 Screener

职责：按策略视图浏览市场和双腿组合，支持搜索、venue 选择、数据质量、价格差、资金费差、深度和排除原因。

计划视图：

1. 同标的跨场所；
2. 跨标的相对价值；
3. 跨场所 funding。

### `/workbench/oil`：Brent–WTI 相对价值

职责：当前第一主模块。比较各价格源的 CL/BZ 历史、当前偏离、腿贡献、时段、展期、价格源差异和指定规模执行摩擦。

### `/workbench/funding`

职责：`asset × venue` funding 矩阵、原生间隔、统一时间单位、结算边界、历史累计和持有成本。

### `/workbench/execution`

职责：按标的、方向和规模比较 L2、RFQ 或场所公式给出的进入与冻结盘口往返成本。不同执行机制分开标识。

### `/workbench/tools/spread`

职责：任意两腿、价格源、权重和时间尺度的研究图。先从油专题抽出成熟接口，再开放通用配置。

### `/workbench/data`

职责：数据源最新时间、覆盖、缺口、schema、生成命令、JSON/CSV 下载和后台任务状态。

## 4. 模块层次

```text
场所适配器
  只读取并保留场所字段与时间语义
        ↓
原始数据存储
  追加式响应/事件，Git 外保存
        ↓
同步与标准观察
  只统一身份、时间和数值；不抹平价格含义
        ↓
分析模块
  spread / ratio / residual / funding / depth / execution
        ↓
研究投影
  为页面和外部调用提供稳定、小而明确的数据结构
        ↓
HTTP 与浏览器页面
```

研究投影是计算模块与前端之间的主要接口。前端不读取原始场所响应，也不重新实现金融计算。

## 5. 价格与执行规则

- K 线收盘、指数、mark、mid、L2 和 RFQ 是不同价格源；
- Brent 与 WTI 是不同基准，原始美元价差不等于套利利润；
- 同步观察只使用明确时间匹配，不用未来值补缺；
- 可执行价格按方向和指定数量取得；
- RFQ、L2 和公式模型不能伪装成同一种盘口；
- 未知费用、funding、展期权重或退出价格保持未知；
- 页面推荐的是研究优先级，不是交易信号。

## 6. 开发顺序

### 阶段 A：当前实施

- 最小 Dashboard；
- Brent–WTI 相对价值数据集与 CLI；
- Lighter、Hyperliquid 公开数据；
- Variational `monte-fox` 市场观察导入；
- 多时间尺度图、冻结模型、机制诊断；
- 指定规模执行摩擦；
- JSON/CSV 和数据健康页面。

### 阶段 B：发现能力

- 全市场 Screener 外壳与统一筛选；
- 同标的跨场所候选；
- RWA/相对价值候选；
- 排除原因和收藏列表。

### 阶段 C：Funding

- Lighter、Hyperliquid、Variational funding 标准模型；
- 历史采集、结算间隔和累计现金流；
- Funding Screener、热力图和持有成本。

### 阶段 D：通用研究工具

- 从油专题抽出 PairDefinition、同步器和图表；
- 任意两腿 Spread Grapher；
- 历史数据导出和可重放实验。

### 阶段 E：回放与实时影子研究

- 入场、退出、机会寿命和执行失败回放；
- 只读实时运行、任务健康和机会雷达；
- 仍不发送真实订单。

## 7. 每日共学产物标准

每天至少增加一种可以再次使用的产物：

- 数据集或采集器；
- CLI 或脚本；
- 分析指标或诊断器；
- 测试 fixture 与可重放案例；
- Dashboard/专题功能；
- 清楚的领域词汇或方法文档。

概念讲解必须连接当日真实数据和实现边界。阅读页面、按钮点击、低难度选择题或填写固定解释不单独算学习成果。

## 8. 验证

每个纵向功能至少验证：

1. 研究投影的确定性行为；
2. HTTP 页面与下载接口；
3. 真实数据采集；
4. 浏览器桌面/窄屏关键流程；
5. 数据新鲜度、未知项和只读声明；
6. 全仓测试与代码审查。
