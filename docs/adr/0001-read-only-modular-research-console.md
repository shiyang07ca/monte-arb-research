# ADR-0001：研究操作台保持只读并按发现与专题分析分层

Status: accepted

Date: 2026-08-22

## Context

现有页面直接展示候选和执行 JSON，既不适合日常发现，也把课程步骤、研究计算和页面交互混在一起。可选方案包括：继续扩充单页、把研究与真实执行合并，或建立只读且按职责拆分的研究操作台。

用户当前需要长期积累可复用数据、脚本、工具和分析模块；真实下单已有独立项目处理。把下单或强制学习表单放进本仓库会扩大安全范围，并使数据与分析难以独立复用。

## Decision

1. 本仓库的浏览器产品是只读研究操作台，不注册执行客户端，不发送订单。
2. Dashboard/Screener 负责发现、筛选、摘要和导航；专题模块负责历史、机制、执行摩擦和数据导出。
3. 计算模块输出稳定研究投影；HTTP 和前端只消费研究投影，不直接解析原始场所响应。
4. 每个专题同时交付可重算数据集、CLI/脚本、测试和页面。
5. Variational 只从 `monte-fox` 读取脱敏市场观察；账户与执行事件不进入本仓库。
6. 每日共学用于逐步增加系统能力和讲解关键概念，不成为页面状态机。

## Consequences

- 研究模块可以在 CLI、浏览器和后续 notebook 中复用；
- 页面替换不会要求重写金融计算；
- 真实执行风险与研究页面隔离；
- 第一版需要额外维护研究投影和数据健康信息；
- 发现模块与专题模块不能依赖一个不透明总分互相跳转；
- 如果未来需要下单，必须在独立设计中重新评估权限、风控、失败恢复和审计，而不是在现有页面上增加按钮。
