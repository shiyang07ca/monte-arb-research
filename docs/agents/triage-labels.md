# Triage 标签

各 engineering skill 使用五个标准 triage 角色。本文件记录这些角色在本仓库 issue tracker 中对应的标签字符串。

| mattpocock/skills 中的角色 | 本仓库 tracker 中的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估此 issue |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 信息完整，可以交给 AFK agent 处理 |
| `ready-for-human` | `ready-for-human` | 需要人类实施 |
| `wontfix` | `wontfix` | 不会处理 |

skill 提到某个角色时，使用右侧对应的标签字符串。若本仓库以后改用其他标签名称，只修改右侧列，不修改左侧标准角色。
