# Day14–21 市场机会研究工作台路线

> 版本：2026-08-18
>
> 状态：当前唯一课程与系统规划
>
> 真实订单：禁止

## 1. 最终成果

持续运行的浏览器研究工作台，而不是八个独立课程页面：

```text
扫描全部市场
→ 发现异常
→ 交易吸引力榜 + 研究价值榜
→ 推荐候选
→ 机制研究与区分性实验
→ 可成交回放与失败模型
→ 实时影子研究
→ 机会雷达扩展
```

用户不写代码；Agent 负责系统实现。用户每天使用真实候选训练发现、解释、实验取舍、证据判断与迁移。

## 2. 每日研究循环

1. 工作台扫描 Lighter–Hyperliquid 全部可映射永续；
2. 分别生成交易吸引力榜与研究价值榜；
3. 综合展示最多 3 个不重复候选；没有足够高质量候选时不凑数；
4. 用户选择一个；
5. 候选页先只显示真实现象和证据；
6. 用户给出简短初步解释；
7. 解锁 Agent 的竞争假设与实验建议；
8. 用户选择或质疑实验；
9. Agent 实现并运行；
10. 用户解释结果；
11. Agent 把结果加入工作台的新指标、实验器、回放、诊断器或雷达。

初步解释不是标准答案，可以是不确定或提出先验证某项事实。

## 3. 双榜

### 交易吸引力榜

- Day14：两种方向的当前可成交价差、当前深度和数据质量；
- Day15：加入持续时间、重复频率和时段基线；
- Day16：加入多个规模、费用、资金费和退出成本；
- Day19：加入执行失败成本和未对冲时间。

### 研究价值榜

- 现象新颖度；
- 是否存在多个竞争解释；
- 是否有高信息增益实验；
- 能否改进工作台；
- 能否迁移到其他市场或场所。

所有组成值和限制透明展示，不隐藏为单一总分。

## 4. Day14–21 里程碑

里程碑允许跨多天。系统能力与用户研究动作都完成，才推进。

| 里程碑 | 工作台新增能力 | 用户真实研究动作 | 完成证据 |
|---|---|---|---|
| Day14 研究工作台 v0 | 自动扫描、当前快照双榜、最多 3 个候选、单候选研究页、实验记录 | 从真实候选中选择一个；先解释现象；选择/质疑一个区分性实验；解释结果 | 结果反哺至少一个可复用指标、实验器或诊断器 |
| Day15 连续数据与异常发现 | WS 连续采集、市场自身基线、持续时间、时段与数据健康 | 从连续数据区分一次噪声、持续异常和时段结构，选择一个继续研究 | 候选不是由单一快照制造；断连和缺口可见 |
| Day16 可执行性与容量 | 多规模盘口走档、共同数量、费用/funding/退出成本曲线 | 选择方向与规模，解释屏幕价差如何变成现金结果 | 候选榜显示多个资金规模的容量与保守结果 |
| Day17 机制实验室 | 竞争假设、区分性实验、session/oracle/roll/funding 诊断 | 比较至少两个机制并选择有区分力的实验；根据结果更新判断 | 实验结果加入 detector、标签或诊断图 |
| Day18 机会回放 | 入场/退出/失效、机会寿命、逐笔纸上交易、实验版本 | 解释结果分布、持有时间、回撤和失败样本 | 不用最佳单笔或反复调参替代整体结果 |
| Day19 执行失败实验室 | 部分成交、第二腿延迟、拒单、撤单晚到、补对冲 | 解释事件序列中的实际敞口、允许动作和最坏结果 | 候选排名纳入执行失败成本 |
| Day20 实时影子研究与机会雷达 | 实时只读扫描、本地 paper、系统健康；雷达探查其他 venue/链上机制 | 从主榜与雷达中选一个方向，判断是否值得适配成本 | 至少一个新方向完成低成本证据核对或正式接入决定 |
| Day21 无提示迁移与路线图 | 未详细讲过的候选、完整研究历史和后续系统路线 | 独立完成候选选择、机制解释、实验取舍、结果解释和下一步 | 工作台、方法、候选/实验历史与扩展路线仍可持续使用 |

## 5. 没有高质量候选时

切换为方法训练，但必须增强同一个工作台：

- 历史真实异常；
- 时间错位、过期或快照故障；
- funding/深度/展期/时段机制案例；
- 新 venue 或链上机会雷达；
- 可复用实验或诊断视图。

不为完成 Day 编号制造候选，不重复浅层 `unknown/exclude` 问答。

## 6. 主扫描与机会雷达

### 主扫描

- Lighter 与 Hyperliquid 全部可映射永续；
- WTI/Brent 为 RWA 基准案例；
- BTC/ETH 为 24/7 对照；
- 全量候选保留，UI 每次优先展示最多 3 个；无高质量候选时转入方法训练。

### 机会雷达

优先侦察：

1. 全部 Hyperliquid HIP-3 RWA；
2. dYdX perpetuals；
3. Architect/AX RWA marketdata；
4. Ostium/Avantis RWA；
5. CEX–DEX funding；
6. Aave/Morpho 借贷与清算；
7. AMM/聚合器跨池 quote。

雷达只做低成本研究。满足数据、产品语义、成本、限制和异象标准后，才正式接入。

## 8. 数据与工具

- 浏览器工作台：日常研究入口；
- Telegram：候选选择、初步解释和研究指令；
- Python/CLI：可复用扫描、实验和回放；
- Jupyter：需要自由探索时使用，不成为唯一运行路径；
- SQLite：候选、研究会话、假设、实验和任务；
- 压缩 JSONL/Parquet：持续市场事件；
- NautilusTrader：进入 Day18–20 前固定版本并建立 Python `>=3.12,<3.15` 的独立环境；通过两个只读数据适配器 smoke test 后，再用于数据目录、历史重放和实时影子运行。

## 9. 学习质量标准

不再用以下事项证明掌握：

- Agent 写完代码；
- 测试通过；
- 页面读完或按钮点击；
- 固定模板填写；
- 浅选择题；
- 哈希、manifest 或状态码；
- 每天输出一份否定报告。

真正的学习证据是用户在真实候选上完成选择、初步解释、实验取舍、结果解释，并在以后不同市场中迁移。

## 10. 时间与边界

- 工作日：30–45 分钟；
- 周末：1–2 小时深挖；
- Agent 后台工程不计入用户时间；
- Day14–21 可跨多天；
- 不注册执行客户端，不发送真实订单；
- 账户只读核验独立运行；
- 工作台推荐不是自动交易信号。
