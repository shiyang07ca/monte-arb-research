# 市场机会研究操作台路线

> 版本：2026-08-22
>
> 状态：当前唯一产品与共学规划
>
> 产品边界：只读研究，不发送订单

## 1. 最终成果

持续运行、可扩展、可二次开发的套利研究操作台，而不是按 Day 复制的课程页面：

```text
Dashboard 与数据健康
→ 全市场 Screener 发现
→ 专题模块分析历史与机制
→ 指定规模执行摩擦
→ 数据导出、回放与诊断
→ 将结论实现为采集器、数据集、指标、测试或页面能力
```

用户不负责写代码。Agent 负责实现、运行、修复与维护；用户理解真实市场中的经济对象、价格语义、机制、执行约束和证据边界。

每日共学是建设同一系统的迭代节奏，不是产品信息架构。页面不按 Day 拆分，也不以填写解释、选择题、按钮点击或完成状态证明掌握。

## 3. 当前主线：Brent–WTI

第一条完整纵向流程：

```text
Lighter + Hyperliquid + Variational 只读导入 + 外部长期参考
→ 同价格源内精确同步
→ 美元价差 / 比值 / 对数比值 / 冻结参考残差
→ 形成窗口与按时间验证窗口
→ 腿贡献 / UTC 时段 / venue 分歧 / roll / funding / 数据健康诊断
→ 指定规模 L2 摩擦
→ JSON / CSV / 来源 manifest
```

必须保持以下边界：

- Brent 与 WTI 是不同基准，美元价差不是无风险套利利润；
- K 线、指数、mark、L2 和 RFQ 是不同价格源；
- 当前执行表是 1:1 场所数量的摩擦基线，不是 beta 对冲或经济中性仓位；
- 合约权重、执行对冲比率、账户费率、持有期 funding 和未来退出未知时保持未知；
- 统计偏离和冻结模型不证明未来均值回归或盈利。

详细规则见 `docs/product/oil-relative-value-v1.md`。

## 5. 数据与计算分层

```text
场所适配器
→ Git 外原始追加式数据
→ 保留价格含义的同步观察
→ spread / ratio / residual / funding / depth / execution
→ 稳定研究投影
→ Dashboard、专题页面、JSON/CSV 与 CLI
```

规则：

- 原始响应不因派生规则变化而覆盖；
- 同步不用未来值或无声明的前值补缺；
- 每个价格源独立显示覆盖、最新时间、缺口和错误；
- 日线缺口需要交易所日历，周末/节假日不能直接记为 feed failure；
- 大型实时投影可重算并保存在 Git 外；仓库提交代码、schema、文档和小型 fixture；
- Variational 仅导入 `monte-fox` 的 `market_observation`，忽略账户、订单与执行事件。

## 7. 每次共学的产物标准

每次迭代至少增加一种可再次使用的产物：

- 数据集或采集器；
- CLI、脚本或稳定接口；
- 分析指标、诊断器或回放器；
- 测试 fixture 与反例；
- Dashboard/专题功能；
- 领域词汇、ADR 或方法文档。

概念必须结合真实数据说明：这个量回答什么、不能回答什么、需要什么下一项证据。固定模板、浅选择题和无价值解释不算产物。

## 8. 系统边界

- 工作台没有交易按钮、签名、钱包或 execution client；
- 账户只读核验若需要，必须在独立安全进程中运行；
- 真实交易实现继续留在独立项目，不并入本研究 UI；
- 工作台给出研究优先级和证据，不输出自动 Go 信号；
- 任何盈利结论必须经过费用、funding、退出、保证金、权限和样本外回放。
