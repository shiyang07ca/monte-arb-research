# Day14–21 研究操作台里程碑

本目录记录持续增强同一个市场机会研究操作台的系统里程碑，不代表每天复制一个独立课程页面。

## 工作方式

```text
真实数据或明确工程缺口
→ 增加数据集、脚本、分析模块、诊断器、测试或页面功能
→ 结合真实结果解释关键概念与边界
→ 将能力复用到下一市场或下一模块
```

Agent 负责编码、采集、测试、运行和维护。用户不需要用低价值解释、固定假设表单、浅选择题或按钮点击证明掌握。

## 完成标准

系统里程碑的工程完成证据包括：

- 能再次运行的数据与代码；
- 明确 public seam 的测试；
- 真实数据和浏览器验收；
- 未知项、阻断项和安全边界；
- 结果已经成为后续可以复用的接口或模块。

用户掌握情况单独评估：能否读懂真实结果、区分量的含义、指出证据边界并迁移到新市场。Agent 写完代码、测试通过、页面读完或哈希清单不能单独证明用户掌握。
