# Day12–21 实战课程

本目录替代旧交互网页。每一课都从当前市场数据或系统故障开始，最后必须留下代码、测试、运行证据和人工决定。

## 每课固定过程

1. 用户在运行前预测结果。
2. 助手展示本次实现和一手资料。
3. 用户审查两到三个关键函数。
4. 用户亲自修改一条会改变结果的规则。
5. 助手注入一个故障，用户定位根因。
6. 保存输入哈希、命令、结果、决定和未知项。

## 决定状态

- **拒绝**：已有事实否定候选。
- **继续采集**：关键事实未知或样本不足。
- **仅模拟**：证据足以进入实时模拟，但没有真实下单授权。

课程完成不自动改变真实交易权限。
