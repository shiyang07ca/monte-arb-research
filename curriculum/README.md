# Day14–21 研究工作台里程碑

本目录不再代表每天独立阅读的一套课程页。Day14–21 是持续增强同一个市场机会研究工作台的 8 个里程碑，每个里程碑可以跨多个工作日或周末。

## 训练方式

```text
工作台扫描真实市场
→ 双榜推荐 3 个候选
→ 用户选择一个并先解释现象
→ 解锁 Agent 竞争假设
→ 用户选择或质疑实验
→ Agent 实现并运行
→ 用户解释结果
→ 结果升级工作台
```

Agent 负责编码、采集、测试和运行。用户不写代码，训练研究和发现机会的能力。

## 完成标准

里程碑只有在两类证据都存在时完成：

1. 工作台新增能力已经实际运行并能复用；
2. 用户在真实候选上完成选择、初步解释、实验取舍和结果解释。

以下事项不能单独证明掌握：Agent 写完代码、测试通过、点击按钮、读完页面、填写固定模板或输出哈希/清单。

## 没有好候选时

使用历史真实异常或故障增强同一个工作台，例如资金费异动、RWA 时段/展期、深度与机会寿命、断连/时间错位或新场所雷达。当天产出必须能再次使用。

- 主扫描 Lighter–Hyperliquid 全部可映射永续；
- WTI/Brent 是 RWA 基准案例，不是唯一范围；
