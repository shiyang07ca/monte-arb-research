# Day12–21 实战课程

本目录替代旧交互网页。每一课都围绕一个当前市场问题或系统故障，目标是理解并实现一项可复用能力，而不是完成固定教学仪式。

## 每课组织原则

1. 先展示真实数据、系统故障或可复现现象，再解释当天需要的技术知识。
2. 助手完成主要实现并实际运行；用户不从空文件开始，也不靠阅读任务清单学习。
3. 每课只选择一个最能暴露理解差异的动作，例如解释结果、审查关键函数、修改规则或诊断故障；不机械要求全部完成。
4. 代码、测试和运行结果必须支持当天的技术结论。哈希、清单和研究记录只服务于复现，不作为学习内容本身。
5. 如果用户已经能把知识迁移到新数据或新故障，就结束本课；如果不能，再针对错误补讲。

Day13–21 当前保留主题与系统成果边界；其中旧式“用户任务”将在每课开始前按上述原则改写，不作为必须逐项完成的现行要求。

## 决定状态

- **拒绝**：已有事实否定候选。
- **继续采集**：关键事实未知或样本不足。
- **仅模拟**：证据足以进入实时模拟，但没有真实下单授权。

课程完成不自动改变真实交易权限。
