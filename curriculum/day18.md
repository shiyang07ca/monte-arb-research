# Day18：机会回放实验室

> 状态：待实现
>
> 里程碑允许跨多个工作日

## 目标

在连续真实数据上把候选机制转成逐笔纸上交易，研究机会寿命、退出条件、结果分布和失败样本。重点不是找到最好参数，而是看清现象在可执行规则下是否重复。

## 工作台新增能力

- 候选窗口到入场/退出/失效规则；
- 真实 L2 与 funding 现金流的逐事件纸上交易；
- 持有时间、机会寿命、收益分布、回撤、容量和失败原因；
- 参数/规则版本和完整实验历史；
- 时间顺序切分与未见窗口；
- 交易榜显示分布和最差结果，不只显示平均或最好单笔。

## 用户研究动作

用户选择：

- 要回放的候选与机制；
- 哪个入场/退出假设最能检验该机制；
- 哪些结果会使其失去研究价值。

Agent 执行后，用户解释：

- 盈亏来自哪种市场行为；
- 失败样本是否集中在某个时段/深度/状态；
- 是否需要更多数据、修改机制还是停止该路线。

## 完成条件

- 每笔纸上交易可由保存事件重算；
- 退出成本和失败样本保留；
- 不以最佳单笔证明策略；
- 参数改变生成新实验，不覆盖旧结果；
- 用户能解释分布、持有时间与机制关系；
- 回放能力加入同一候选页并可用于其他市场。
