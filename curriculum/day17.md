# Day17：机制实验室

> 状态：待实现
>
> 里程碑允许跨多个工作日

## 目标

把“看到了异常”推进到“哪个机制更可能产生它”。用户训练竞争假设与区分性实验，不接受 Agent 单一解释。

## 工作台新增能力

- Hypothesis 对象：机制、支持/反对证据、若为真还应看到什么；
- Experiment 对象：要区分哪些解释、结果 A/B 各改变什么判断；
- session、oracle、roll、funding、OI、trade flow、depth 与 latency 实验组件；
- 实验运行前后快照和版本；
- 结果可生成新 detector、标签或诊断图；
- 历史实验可在新资产/venue 重跑。

## 用户研究动作

针对一个真实候选：

1. 先给出初步机制；
2. 查看 Agent 的 2–4 个竞争解释；
3. 选择一个真正能区分解释的实验，或指出建议实验为何没有区分力；
4. 根据结果更新判断；
5. 指出应当加入工作台的通用能力。

## 可能实验

- 异常是否只在某个 external/internal session 出现；
- spread 先变化还是 funding/OI/flow 先变化；
- 目标规模增加时异常是否迅速消失；
- 与第三个 venue 或底层参考市场比较；
- 展期/维护/恢复前后是否重复；
- 排除接收延迟后是否仍存在。

## 完成条件

- 同一候选至少保持两个可证伪解释；
- 实验预先写明不同结果的含义；
- 用户能指出哪个证据支持、反对或与机制无关；
- 结果产生至少一项可复用实验器或 detector；
- 几天后在不同市场重新使用该方法。
