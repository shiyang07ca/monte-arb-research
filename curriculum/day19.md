# Day19：执行失败实验室

> 状态：待实现
>
> 里程碑允许跨多个工作日

## 目标

把纸上交易从“假设四次成交都成功”升级为双腿真实状态与失败成本。用户训练从事件序列判断实际敞口、允许动作和最差后果。

## 工作台新增能力

- 订单、确认、部分成交、完全成交、拒单、撤单与晚到成交分开；
- 双腿仓位、现金、剩余敞口与旧订单风险；
- 第二腿延迟、盘口移动、补对冲、减仓和停止；
- 主动成交基线与挂单/补对冲方案分开；
- 故障场景可在候选回放中切换；
- 交易吸引力榜纳入失败成本和未对冲时间。

## 用户研究动作

工作台给出一个来自真实候选窗口的失败事件序列。用户解释：

- 当前实际持有什么；
- 哪些旧订单仍可能改变敞口；
- 可选择的动作及代价；
- 哪个失败风险足以使候选不值得继续。

Agent 运行不同动作后，用户比较最坏结果，不做机械状态名选择题。

## 完成条件

- 仓位和现金由成交事件重算；
- 确认不等于成交；
- 旧订单终止前不会盲目补单；
- 主动与挂单方案使用不同证据；
- 用户能解释至少一个部分成交/第二腿失败场景；
- 失败成本进入双榜与候选研究页。
