# Day16：可执行性与容量

> 状态：待实现
>
> 里程碑允许跨多个工作日

## 目标

把候选榜上的“价差”转成不同资金规模下真实可成交的进出场结果。用户训练选择方向、规模和持有假设，并理解屏幕价差与现金结果的差异。

## 工作台新增能力

- 两种开仓方向分别走真实 L2；
- 两边共同合法数量、最小名义、精度和保证金限制；
- `$10 / $25 / $50 / $100 / 自定义` 等多个规模的 VWAP 与容量曲线；
- 开仓与退出四次主动成交；
- 实际/保守费率、funding、退出滑点和未成交量；
- 当前结果、成本区间与缺失证据分开；
- 交易吸引力榜按规模展示，不用中间价总分。

## 用户研究动作

从三个真实候选中选择一个方向与研究规模，说明：

- 为什么这个规模有意义；
- 哪一项成本最可能改变结论；
- 如果持有时间改变，哪里需要重新计算。

Agent 运行容量与现金实验后，用户解释结果曲线，而不是只回答正负。

## 完成条件

- 多个规模、两个方向可从冻结 L2 重算；
- 深度不足保留未成交数量；
- mark/oracle/mid 不替代成交价；
- 未知账户费率不填公开默认零成本；
- 用户能解释候选在哪个规模失去吸引力，以及为什么；
- 结果形成工作台通用容量视图和交易榜特征。
